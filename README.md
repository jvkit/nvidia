# nvidia

> NVIDIA 加速数据科学认证（NCA）备考实录单页网站

<p><img src="https://img.shields.io/badge/lang-HTML-blue?style=flat-square"/></p>

## 简介
这是一个静态单页网站，完整记录从 pandas 到 cuDF、21 天备考 NVIDIA Certified Associate: Accelerated Data Science 认证的历程：报考初心、三周备考攻略，以及苏州开发者日线下考试的流程与心得。

## 技术栈
静态 HTML / CSS / JavaScript（单文件 index.html）

## 快速开始
无需构建，直接用浏览器打开 `index.html`，或本地起一个静态服务器：

```bash
python3 -m http.server 8000
```
然后访问 http://localhost:8000 。
